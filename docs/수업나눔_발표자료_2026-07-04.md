# 수업나눔 발표자료
## 「컴퓨터 전공이 AI를 활용하는 법」
### — 나이스·에듀파인 업무 자동화 도구를 AI와 함께 만들며 —

발표자: 권혁규 | 예상 시간: 15~20분 | 대상: 동료 교사

---

## 🎯 이 발표의 한 문장 메시지
> **"코드를 다 외워서 짜는 시대가 아니라, AI에게 '무엇을 원하는지' 잘 설명하고
> 막히면 '왜 안 되는지 진단시키며' 함께 만드는 시대다."**

전공자든 아니든, AI를 **'대화 상대이자 디버깅 파트너'** 로 쓰는 방법을 실제 사례로 보여준다.

---

## 📑 슬라이드 구성 (총 13장)

### [1] 표지
- 제목: 컴퓨터 전공이 AI를 활용하는 법
- 부제: 매일 쓰는 나이스·에듀파인, 자동화 도구를 AI와 함께 만들다
- (말): "오늘은 제가 AI를 '어떻게' 활용했는지, 실제로 만든 업무 도구를 예로 보여드리겠습니다."

### [2] 왜 만들었나 — 우리 모두의 불편함
- 나이스/에듀파인, 접속할 때마다 인증서 로그인 반복
- 조금만 딴짓하면 **자동 로그아웃** → 또 로그인
- 결재·공람 올라온 걸 **제때 못 봄**
- (말): "전공을 떠나서, 이건 그냥 제 업무가 불편해서 시작했습니다."

### [3] 무엇을 만들었나 — 결과 먼저 (데모/스크린샷)
- ① 원클릭 자동 로그인 (EVPN→인증서→나이스→에듀파인)
- ② 세션 자동 유지 (로그아웃 안 됨)
- ③ **결재 늘면 윈도우 알림**
- ④ 파이썬 없는 동료도 쓰게 **exe로 배포**
- (말): "먼저 완성된 모습을 보시죠." → 콘솔 화면 시연 or 캡쳐

### [4] 핵심 — 저는 이걸 '혼자' 짜지 않았습니다
- 화면 절반: 나(요구사항·판단·테스트) / 절반: AI(코드 작성·진단·수정)
- **AI 코딩 도구 'Claude Code'** 사용 — 내 PC의 파일을 직접 읽고·고치고·실행
- (말): "저는 '무엇을' 원하는지 말하고, 'AI가' 코드를 씁니다. 막히면 같이 풉니다."

### [5] 개발 방법 = '반복 대화' 한 사이클
```
   ①요구사항 말하기  →  ②AI가 코드 작성  →  ③실행해 보기
        ↑                                        │
        └──── ⑤AI가 원인 진단·수정  ←  ④안 되면 '증상' 전달(캡쳐·에러) ──┘
```
- 핵심은 **④번**: 안 될 때 "안 돼요"가 아니라 **화면 캡쳐 + 정확한 증상**을 준다
- (말): "코딩이 아니라 '증상 설명'이 실력입니다. 병원에서 의사에게 증상 말하듯이요."

### [6] 실제로 막혔던 순간 ① — 클릭 좌표가 자꾸 빗나감
- 증상: 인증서 암호칸을 눌러야 하는데 엉뚱한 곳 클릭
- 내가 한 것: 화면 캡쳐 + "여길 눌러야 하는데 여길 눌러요" 전달
- AI 진단: "모니터 기준 좌표라 그래요 → **창 기준 좌표로** 바꾸면 해상도 바뀌어도 안 깨져요"
- (말): "AI가 근본 원인을 짚어주니, 임시방편이 아니라 제대로 고쳐졌습니다."

### [7] 실제로 막혔던 순간 ② — 팝업 때문에 멈춤
- 증상: 로그인 중 'AXGATE 열기' 팝업에서 자동화가 멈춤
- AI 진단: "그건 웹 요소가 아니라 **크롬이 띄우는 네이티브 창**이라, 코드로는 다르게 눌러야 해요"
- 해결: 팝업을 자동 감지해 '확인' 처리
- (말): "제가 몰랐던 '왜 안 되는지'를 AI가 설명해줬어요. 배우면서 만든 거죠."

### [8] 실제로 막혔던 순간 ③ — ⭐하이라이트⭐ '어제는 됐는데 오늘 안 됨'
- 증상: 손으로는 로그인 되는데, 자동화만 "아이디/비밀번호 확인 필요"
- AI가 한 것: **로그인 사이트의 실제 코드를 직접 뜯어봄** → 정상 경로 확인 → "그럼 비번 글자가 다른 것"
- 범인: 비밀번호 끝 `！`(전각) vs `!`(반각) — **눈엔 똑같지만 컴퓨터엔 다른 글자**
- (말): "사람은 절대 못 찾을 한 글자 차이를, AI가 논리적으로 추적해서 잡았습니다. 이게 AI 활용의 진짜 힘이에요."

### [9] 그래서 완성된 것
- 통합 콘솔 하나로: 로그인·세션유지·결재관제·조회·문서템플릿
- (말): "작은 요청들이 쌓여서, 매일 쓰는 도구가 됐습니다."

### [10] AI를 잘 쓰는 법 — 오늘의 핵심 4가지
1. **증상을 구체적으로** — 캡쳐·에러메시지·"어디서 멈췄는지"
2. **작게, 여러 번** — 한 번에 완성 말고 조금씩 고쳐가기
3. **모르면 진단시켜라** — "왜 안 되는지 네가 찾아줘"
4. **남들도 쓰게 포장** — 결과물을 exe로 만들어 나눔
- (말): "전공 지식보다 이 '대화하는 습관'이 훨씬 중요합니다."

### [11] 다른 선생님도 쓸 수 있게 — 배포
- 파이썬 설치 없이: **exe + 크롬런처 + 사용법** 3종 세트를 USB로
- (말): "코드는 저만 보지만, 결과물은 누구나 더블클릭으로 씁니다."

### [12] 여러분도 할 수 있어요 — 이렇게 부탁하면 됩니다
- 예시 프롬프트:
  - *"나이스에 매번 로그인하기 귀찮은데, 자동 로그인 프로그램 만들어줘. 순서는 이렇고…"*
  - *"이 화면에서 여기 버튼을 눌러야 하는데 안 눌려. (캡쳐) 왜 그럴까?"*
- 전공 아니어도 **'무엇을 원하는지'만 말하면** 시작됩니다
- (말): "오늘 배운 4가지만 기억하시면, 여러분도 내일부터 하실 수 있어요."

### [13] 마무리
- "AI는 '나 대신 해주는 도구'가 아니라 **'나와 함께 푸는 파트너'** 입니다."
- "전공자의 역할은 코드 암기가 아니라, **좋은 질문과 정확한 증상 전달, 그리고 판단**입니다."
- 감사합니다 / Q&A

## 🗣️ 발표 팁
- [3]번에서 **실제 콘솔을 켜서 시연**하면 몰입도 최고. (미리 디버그크롬 로그인 세팅 후 알림 한 번 띄워보기)
- [8]번(전각/반각)은 **가장 임팩트 있는 이야기** — 시간 부족하면 여기에 집중.
- 코드 화면은 **길게 보여주지 말 것**. "이런 걸 AI가 썼다" 정도로 흘리고, 이야기(증상→진단→해결)에 집중.
- 마지막 [12]번에서 **청중이 따라할 수 있는 프롬프트 예시**를 꼭 남기기 (수업나눔의 실용성).
