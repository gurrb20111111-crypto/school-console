# 학교업무 통합 콘솔 (school_console.py)

원본 `sen_login_keepalive.ahk` + `session_keeper.py`를 **GUI 하나로 통합**한 버전입니다.
GPT가 만든 v2처럼 "안 될 자동입력"을 욕심내지 않고, **확실히 되는 것만** 한 화면에 모았습니다.

## 무엇이 좋아졌나 (v2 대비)
| 항목 | GPT v2 | 이 콘솔 |
|---|---|---|
| 세션 유지 | 검은 콘솔창 별도 실행 | **GUI 표로 실시간 상태**(사이트별 마지막/다음 갱신) |
| 응답성 | 자동입력 중 UI 멈춤 | **모든 통신 백그라운드 스레드** → 안 멈춤 |
| 나이스 iframe | top 문서만 봄(못 찾음) | **iframe 안까지 재귀**로 탐색(엿보기) |
| 자동입력 | 작동 보장 안 됨(과장) | 입력 자동화는 빼고, **안전한 '읽기(엿보기)'** 로 대체 |
| 템플릿 | 있음 | 복무 사유·기안 문구 → **클립보드** (그대로 유지) |
| 세션연장 로직 | 옛 방식(가짜 성공) | **session_keeper.py v2와 동일한 '진짜' 연장** 내장 |

## 세션 유지 — v2 '진짜' 로직 (중요)
옛날 방식(`fetch(main)`+가짜 마우스)은 진짜 연장 경로를 안 건드려서 나이스가 그대로 만료됐습니다.
이 콘솔의 세션 유지는 `session_keeper.py` v2와 동일하게 동작합니다:
- **공통**: 매 주기마다 `Page.setWebLifecycleState=active`로 얼어붙은 백그라운드 탭을 깨움.
- **나이스**(`mode: neis`): 사이트가 쓰는 그대로 `POST /sessionExtension.do` 직접 호출 →
  응답에 `Y`가 있을 때만 '정상'. '연장하시겠습니까?' 창이 떠 있으면 그 버튼에 신뢰된 클릭.
- **에듀파인**(`mode: edupine`): Nexacro라 DOM 클릭이 안 먹혀서, '연장' 버튼 화면좌표에
  신뢰된 클릭을 보내고 타이머가 리셋됐는지 검증.
- **기타**(`mode: button`): 화면의 '연장' 글자 버튼 클릭 + 서버 GET.

대시보드 상태표의 '상태'는 정직하게 표시됩니다: `정상`(연장 확인), `경고`(응답이 Y가 아님/타이머 안 늘어남), `탭없음`, `실패`.

## 실행 방법
1. 이 폴더(`files`)에서 한 번만: `python -m pip install -r requirements.txt`
2. `python school_console.py`
3. 콘솔에서 **① 로그인 자동화 실행** → 크롬이 디버그 모드로 뜨고 로그인됨
4. **세션 대시보드 → 세션 유지 시작**

> 이 콘솔은 크롬을 직접 띄우지 않고, AHK가 띄운 디버그 크롬(포트 9222)에 **붙어서** 동작합니다.
> 그래서 반드시 ①을 먼저 해야 합니다.

## 탭 설명
- **세션 대시보드**: 세션 유지 시작/중지, 지금 갱신, 사이트별 상태 표.
- **결재 관제**: 크롬 확장 2종(E알리미 알리미 · 에듀파인 결재카운팅)을 콘솔로 통합.
  로그인된 탭에서 `결재/공람` 건수와 `E알리미` 결재서류 목록을 주기적으로 읽어,
  **늘어나면 데스크톱 알림**(plyer)을 띄움. 첫 확인은 조용히 시드(헛알림 방지),
  '직전 건수/이미 본 서류'는 `school_console_state.json`에 저장돼 재시작해도 유지됨.
  → E알리미는 별도 로그인이므로, 상단 **E알리미 열기**로 디버그 크롬에 띄운 뒤 로그인해 두세요.
- **조회 대시보드**(읽기 전용): 열려 있는 결재/문서 **목록 화면**을 읽어 표(제목·기안자·일시)로 보여줌.
  행을 **더블클릭하거나 ‘선택 항목 열기’** 를 누르면 그 문서 위치에 신뢰클릭을 보내 **바로 이동**.
  아래 **출결 미마감 점검**은 나이스 ‘출결 현황’ 화면에서 학급별 마감/미마감을 읽어,
  기준시각(기본 15:00)이 지났는데 미마감이 있으면 **알림**. 입력·제출은 하지 않음.
  → 목록/학급이 안 잡히면 설정 파일의 `doclist_sources`·`attendance`(class_re, unclosed_words 등)를
  현장 화면 용어에 맞게 조정하면 됨.
- **알림장**: 그날 전달사항을 **알림장 앱을 띄우지 않고** 학교 알림장 서버(MySQL)에서 바로 읽어옵니다.
  일자를 고르고 [불러오기] → 알림장 앱이 쓰는 것과 같은 조회(`SELECT * FROM ALIM WHERE ALDATE=<날짜>`)를
  그대로 실행해 부서별([교무부] 등)로 정리해 보여줍니다. 서버는 **학교망 안 또는 EVPN**에서만 열립니다.
  서버에 못 닿으면 예전처럼 **실행 중인 앱 창을 읽는 방식으로 자동 폴백**합니다.
  → 접속값은 설정의 `alim_db`(host 비우면 `MYSET.DBF`의 서버IP 자동, 앱 자신의 기본 접속정보). `pymysql` 필요(자동 설치).
- **복무·기안 템플릿**: 사유/기안 문구 생성 → 복사. (확실히 되는 시간 절약 기능)
- **나이스 업무 → 출결 마감**: 나이스 ‘일일출결관리(담임용)’ 화면에 **실제로 입력**합니다.
  [명단 불러오기]가 날짜를 조회하고 번호·성명·현재 출결 상태까지 읽어오면, 문제 있는 학생만
  **예외 지정**(구분·종류·교시·사유) → [나이스에 입력]. 지정 안 한 학생은 건드리지 않습니다.
  입력이 끝나면 **저장할지 한 번 물어보고**, 나이스 결과창의 글자를 읽어 성공 여부를 가립니다.
  **마감(확정)은 누르지 않습니다** — 나이스에서 직접 ‘출결마감’ → ‘확인’ 하세요.
  → 조퇴·지각은 **교시가 필수**입니다. 교시가 빈 줄이 하나라도 있으면 나이스가 그날 저장을
  통째로 거부해서 같은 날 다른 학생까지 안 들어갑니다. 콘솔이 미리 막습니다.
  → 선택자가 안 맞는 것 같으면 [화면 진단](읽기만 함)으로 콘솔이 무엇을 보고 있는지 확인하세요.
- **엿보기(실험)**: 로그인된 탭에서 키워드가 든 짧은 텍스트를 **읽어서** 보여줌(클릭/입력 없음).
  실제 화면 용어(예: `미결`, `결재대기`, `수신함`)로 키워드를 바꾸면 결재 대기 항목을 빠르게 훑을 수 있음.
- **설정**: AHK 경로, 크롬 경로, 디버그 포트, 갱신 주기.

## 기존 `세션유지_실행.bat`와 충돌?
- AHK 마지막 단계가 `세션유지_실행.bat`를 자동 실행합니다. 이 콘솔의 '세션 유지'를 쓸 거면,
  둘이 같이 돌아도 무해하지만(중복 갱신일 뿐) 깔끔하게 하려면 AHK 끝부분의 bat 자동실행 줄을 빼세요.

## ⚠ 보안 (꼭 확인)
- `sen_login_keepalive.ahk` 81번 줄에 **인증서 비밀번호가 평문**으로 들어 있습니다.
  USB로 들고 다니면 분실 시 인증서+비번이 함께 노출됩니다.
  발표(수업나눔)에서 코드를 띄울 때도 가려야 합니다. 가능하면 실행 시 입력받도록 바꾸는 걸 권장.

## 한계 (솔직하게)
- 나이스 4세대는 **eXbuilder6**(`window.cpr`, `.cl-*` 클래스), K-에듀파인은 **Nexacro** 입니다.
  둘 다 화면 구조가 바뀌면 선택자가 어긋날 수 있습니다.
  '엿보기'도 키워드/구조가 안 맞으면 결과가 비어 있을 수 있습니다 → 키워드를 현장 용어로 조정하세요.
- 출결은 **[저장]까지만** 합니다. ‘출결마감’(확정)과 복무 ‘상신’ 버튼은 자동으로 누르지 않습니다(의도된 안전장치).
- 동명이인이 있으면 그 학생은 **넣지 않고 실패로 알립니다**. 잘못 넣는 것보다 안 넣는 편이 낫습니다.
